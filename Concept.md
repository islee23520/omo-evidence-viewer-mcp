# OmO Evidence Viewer MCP

A small Bun HTTP gallery for showing reviewed, non-sensitive visual evidence in a browser. It lists a dedicated public evidence directory and narrowly scoped local preview routes. The LaunchAgent keeps the server available on a personal Mac. This project does not currently implement MCP; the requested repository name is a name, not a protocol claim.

Stack: Bun 1.4+, JavaScript, macOS LaunchAgent. No additional runtime dependencies.
