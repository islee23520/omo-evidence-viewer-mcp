# Repository instructions

This project serves reviewed, non-sensitive visual evidence over HTTP. Keep machine-specific preview sources and personal paths outside version control. Do not commit evidence artifacts, credentials, or private file paths.

## Repository workflow

Before edits, fetch all remotes, report current branch/upstream/status/target, and preserve dirty work. Use a feature branch for changes unless direct target work is expressly permitted. Commit only verified atomic changes, push the configured upstream, and report branch relation to target. Never force-push or discard local data without approval.

Read Concept.md and ToDo.md before editing product code. Work on one current module at a time; verify locally before committing and pushing.
